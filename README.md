# EvoNext

GUI Agent trajectory workbench and evolution control plane.

This repository is a clean-room implementation. It retains OpenCUA-compatible JSON exchange (`task_id`, `instruction`, `traj`), MongoDB, MinIO and PostgreSQL, and uses Langfuse for model observability. Existing platforms remain supported through explicit compatibility adapters, not copied implementation code or uncontrolled dual writes.

Only synthetic examples belong in this public repository. Never commit credentials, internal endpoints, production trajectories, screenshots, private implementation source, or user data.

The initial foundation is being assembled and validated; this README will be updated with executable setup instructions and an explicit implementation status.
